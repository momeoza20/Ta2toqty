# Tota Love Site
A romantic interactive one-page site inspired by the reference video.

## Included
- Tota-specific welcome screen
- YES / NO interaction; NO button escapes
- "Together forever🫶" transition
- 4 personal memories using the uploaded photos
- Uploaded Mohammed Saeed song with record animation
- 3 clickable gift cards
- Final message exactly as supplied
- Simple private access gate (change the code in `script.js`)

## Important privacy note
The access gate is a front-end convenience, not server-grade security. Anyone who gets the files can inspect the code. For true private hosting, use a server-side password/auth system.

## Run
Open `index.html` in a browser. For best audio behavior, serve the folder through a local/static web server.
